# Centro de Cotizaciones — Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the React + Vite frontend (deployed to Vercel) that replicates every screen and flow from the reference mockup (`centro-cotizaciones_10.html`) against the now-implemented and reviewed backend API, with real login instead of the mockup's `window.storage`.

**Architecture:** A Vite SPA (`frontend/`) with React Router for navigation, TanStack Query for all server data (cache, loading/error states), a thin `api/` layer (one file per backend resource) that talks to the Express API over `fetch` with `credentials: 'include'`, and Tailwind + hand-written shadcn-style primitives for UI, matching the mockup's exact color palette. Auth state lives in a React context backed by `GET /auth/me`; the CSRF token issued at login is held in a module-level variable read by the API client, never in a React state re-render path.

**Tech Stack:** React 18, Vite, React Router 6, `@tanstack/react-query`, Tailwind CSS, `class-variance-authority` + `clsx` + `tailwind-merge` (shadcn-style variant primitives, hand-written — no CLI/registry dependency), Chart.js + `react-chartjs-2`, `html2canvas` + `jspdf`, Vitest + React Testing Library for tests.

## Global Constraints

- The backend is already implemented, reviewed, and tested (see `docs/superpowers/plans/2026-09-08-backend.md` and `docs/superpowers/specs/2026-09-08-centro-cotizaciones-design.md`, section 6 for the verified API surface). This plan builds against that exact API — do not invent or assume endpoints beyond what's documented there.
- **API responses use `snake_case` column names** (e.g. `correlativo_general`, `client_id`, `fecha_aprobacion`) since they come straight from Postgres rows; **request bodies the frontend sends use `camelCase`** (e.g. `clientId`, `lineaServicio`) matching what the backend route handlers read. The `api/` layer is responsible for mapping every `GET` response's `snake_case` fields to `camelCase` before handing data to components — never let a raw snake_case field leak into a component or page.
- **`monto`/`impuestos` on quotation rows come back from Postgres as strings** (NUMERIC columns are JSON-stringified, not native numbers) — the `api/quotations.js` mapper must `Number()`-coerce both before returning data to components. Dashboard endpoint responses are already plain numbers (computed server-side) and need no coercion.
- Auth is session-cookie based (`credentials: 'include'` on every fetch) — never store a token in `localStorage`. The CSRF token from `POST /auth/login` / `GET /auth/me` must be sent as the `X-CSRF-Token` header on every mutating request (POST/PUT/PATCH/DELETE).
- API base URL comes from `VITE_API_URL` (Vite env var, must be prefixed `VITE_` to be exposed to client code), defaulting to `http://localhost:4000` for local dev against the backend's default port.
- Color palette (from the mockup, reproduced as Tailwind theme tokens — use these exact hex values, do not approximate):
  `ink #26262a`, `paper #ffffff`, `muted #f3f1fb`, `border #e4e1f0`, `border-strong #c9c5de`,
  `accent #E8823C`, `accent-ink #4A2A0C`, `ui-accent #6f4bc9`, `ui-accent-ink #2e1f57`,
  `text-secondary #726f85`, `danger #c0392b`, `success #1f8a4c`, `info #3d55c9`, `brand-deep #22201f`.
  Font: Inter (Google Fonts), matching the mockup.
- UI primitives are **hand-written shadcn-style components** (cva variants + Tailwind), not installed via the shadcn CLI — this repo's sandboxed dev environment should not depend on a registry fetch to build. The `Select` primitive wraps a plain native `<select>` (the mockup never uses a searchable combobox, just dropdowns), not a Radix listbox.
- All backend code lives under `backend/`; all frontend code lives under `frontend/` — same monorepo layout the backend plan established.
- Tests use Vitest + `@testing-library/react`, co-located as `*.test.jsx` next to the file under test. Mock the `api/` layer (`vi.mock`) in component/page tests — no real network calls, no real backend dependency for the test suite (that's what the Task 13 local smoke test is for).
- Functionality must match `centro-cotizaciones_10.html` 1:1 — no new features beyond what the mockup has, plus the login screen the backend introduced.
- **Git commits in this repo must NOT include any Claude/Anthropic attribution line** (no `Co-Authored-By: Claude...`, no "Generated with Claude Code" footer) — commit as the user's own account, per this repo's established convention.

`frontend/src/lib/utils.js`:

```js
import { clsx } from 'clsx';
import { twMerge } from 'tailwind-merge';

export function cn(...inputs) {
  return twMerge(clsx(inputs));
}

export function fmtMoney(n, currency = 'GTQ') {
  const value = Number(n) || 0;
  const symbol = currency === 'USD' ? '$' : 'Q';
  return symbol + value.toLocaleString('es-GT', { minimumFractionDigits: 2, maximumFractionDigits: 2 });
}

export function fmtDate(d) {
  if (!d) return '—';
  const dt = new Date(d + 'T00:00:00');
  return dt.toLocaleDateString('es-GT', { day: '2-digit', month: 'short', year: 'numeric' });
}
```

```js
const MUTATING_METHODS = new Set(['POST', 'PUT', 'PATCH', 'DELETE']);

async function request(path, { method = 'GET', body } = {}) {
  const headers = { 'Content-Type': 'application/json' };
  if (MUTATING_METHODS.has(method)) {
    const token = getCsrfToken();
    if (token) headers['X-CSRF-Token'] = token;
  }

  const res = await fetch(`${API_URL}${path}`, {
    method,
    credentials: 'include',
    headers,
    body: body !== undefined ? JSON.stringify(body) : undefined
  });

  const text = await res.text();
  let data = null;
  if (text) {
    try { data = JSON.parse(text); } catch { data = null; }
  }

  if (!res.ok) {
    const error = new Error((data && data.error) || `Error ${res.status}`);
    error.status = res.status;
    throw error;
  }
  return data;
}

export const api = {
  get: (path) => request(path),
  post: (path, body) => request(path, { method: 'POST', body }),
  patch: (path, body) => request(path, { method: 'PATCH', body }),
  put: (path, body) => request(path, { method: 'PUT', body }),
  delete: (path) => request(path, { method: 'DELETE' })
};
```

```jsx
import { createContext, useContext, useEffect, useState, useCallback } from 'react';
import { authApi } from '../api/auth.js';
import { setCsrfToken } from '../lib/csrfToken.js';

const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);
  const [status, setStatus] = useState('loading');

  useEffect(() => {
    authApi.me()
      .then((data) => { setUser(data.user); setCsrfToken(data.csrfToken); setStatus('authenticated'); })
      .catch(() => { setStatus('anonymous'); });
  }, []);

  const login = useCallback(async (email, password) => {
    const data = await authApi.login(email, password);
    setUser(data.user);
    setCsrfToken(data.csrfToken);
    setStatus('authenticated');
  }, []);

  const logout = useCallback(async () => {
    await authApi.logout();
    setUser(null);
    setCsrfToken(null);
    setStatus('anonymous');
  }, []);

  return <AuthContext.Provider value={{ user, status, login, logout }}>{children}</AuthContext.Provider>;
}

export function useAuth() {
  const ctx = useContext(AuthContext);
  if (!ctx) throw new Error('useAuth debe usarse dentro de AuthProvider');
  return ctx;
}
```

```js
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { api } from '../lib/apiClient.js';

function mapClient(row) {
  return {
    id: row.id,
    code: row.code,
    name: row.name,
    country: row.country,
    contactName: row.contact_name,
    contactEmail: row.contact_email,
    contactPhone: row.contact_phone,
    seq: row.seq
  };
}

export function useClients() {
  return useQuery({
    queryKey: ['clients'],
    queryFn: async () => (await api.get('/clients')).map(mapClient)
  });
}

export function useCreateClient() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: (payload) => api.post('/clients', payload).then(mapClient),
    onSuccess: () => queryClient.invalidateQueries({ queryKey: ['clients'] })
  });
}

export function useUpdateClient() {
```

```js
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { api } from '../lib/apiClient.js';

export function mapQuotation(row) {
  return {
    id: row.id,
    correlativoGeneral: row.correlativo_general,
    correlativoCliente: row.correlativo_cliente,
    fecha: row.fecha,
    validezDias: row.validez_dias,
    clientId: row.client_id,
    clienteNombreLibre: row.cliente_nombre_libre,
    pais: row.pais,
    lineaServicio: row.linea_servicio,
    executiveId: row.executive_id,
    proyecto: row.proyecto,
    descripcion: row.descripcion,
    detalle: row.detalle,
    monto: Number(row.monto),
    impuestos: Number(row.impuestos),
    moneda: row.moneda,
    estatus: row.estatus,
    fechaAprobacion: row.fecha_aprobacion,
    fechaCierreProyecto: row.fecha_cierre_proyecto,
    observaciones: row.observaciones,
    version: row.version,
    previousVersionId: row.previous_version_id,
    supersededBy: row.superseded_by,
    rootId: row.root_id
  };
}

function toQueryString(filters = {}) {
  const params = new URLSearchParams();
  if (filters.clientId) params.set('clientId', filters.clientId);
  if (filters.executiveId) params.set('executiveId', filters.executiveId);
  if (filters.estatus) params.set('estatus', filters.estatus);
  const qs = params.toString();
  return qs ? `?${qs}` : '';
}

export function useQuotations(filters = {}) {
  return useQuery({
    queryKey: ['quotations', filters],
    queryFn: async () => (await api.get(`/quotations${toQueryString(filters)}`)).map(mapQuotation)
  });
}

export function useQuotation(id) {
  const { data: quotations, ...rest } = useQuotations();
  return { ...rest, data: quotations ? quotations.find((q) => String(q.id) === String(id)) : undefined };
}

export function useCreateQuotation() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: (payload) => api.post('/quotations', payload).then(mapQuotation),
    onSuccess: () => queryClient.invalidateQueries({ queryKey: ['quotations'] })
  });
}

export function useUpdateQuotation() {

    mutationFn: ({ id, ...payload }) => api.patch(`/quotations/${id}`, payload).then(mapQuotation),

  });
```

`frontend/vercel.json`:

```json
{
  "buildCommand": "npm run build",
  "outputDirectory": "dist",
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```

(The `rewrites` entry is required for a client-side-routed SPA: any deep link like `/historial` must serve `index.html` so React Router can take over, instead of Vercel 404ing on a path that isn't a real file.)

```markdown
React + Vite SPA para el Centro de Cotizaciones de VaoVao.
```
